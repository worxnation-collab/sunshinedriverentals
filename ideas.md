## Constraint
This is a CX refinement, NOT a redesign. The visual identity must be preserved exactly:
- Brand colors: Warm cream/sand background (#f5f0e8), F8 Green accent (#4a7c59 / lime-green highlights), dark charcoal text, amber/gold highlights
- Typography: Bold serif/display for headlines, clean sans for body

## Approach A — Refined Warmth (CHOSEN)

**Design Movement**: Premium Southern Hospitality meets Performance Automotive

**Core Principles**:
1. Preserve every existing color, font, and layout pattern — only refine spacing, contrast, and hierarchy
2. Mobile-first CTA placement: booking buttons must be thumb-reachable on every page
3. Trust signals (insurance badge, 5-star rating, owner photo) elevated to above-the-fold on mobile
4. Reduce cognitive load: one primary CTA per section, secondary actions visually subordinate

**Color Philosophy**: The existing warm cream background communicates approachability and local ownership. The F8 Green accent signals the fleet's signature color. Amber/gold highlights add warmth. No color changes — only contrast improvements for accessibility.

**Layout Paradigm**: Existing asymmetric hero sections preserved. Fleet cards get a cleaner grid with consistent image aspect ratios. Sticky mobile nav with booking CTA always visible.

**Signature Elements**:
1. Sticky "Book Now" bar on mobile that appears after scrolling past the hero
2. Vehicle spec pills (existing pattern) made more scannable with consistent sizing
3. Trust bar (Wheelbase-insured, 5-star Google, Owner-operated) as a persistent strip below hero

**Interaction Philosophy**: Smooth scroll anchors, FAQ accordions that open cleanly, form fields with clear labels and validation states.

**Animation**: Minimal — existing page feel preserved. Only add: smooth scroll behavior, subtle card hover lift (2px translateY), FAQ accordion open/close transition.

**Typography System**: Preserve existing font stack. Improve line-height and letter-spacing on mobile for readability.
